
# Netflix Content Type Analysis

## Project Overview
This project analyzes Netflix content to understand the distribution of Movies and TV Shows using Python.

## Dataset
- Dataset: netflix_cleaned.csv
- Total Records: 8,790
- Total Columns: 10

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
1. Loaded the Netflix dataset.
2. Counted Movies and TV Shows.
3. Calculated content percentages.
4. Created a Pie Chart.
5. Created a Bar Chart.

## Key Findings
- Total Movies: 6,126
- Total TV Shows: 2,664
- Movies Percentage: 69.69%
- TV Shows Percentage: 30.31%

Movies represent the majority of Netflix content in this dataset.
