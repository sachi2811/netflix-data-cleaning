
# Netflix Country-Wise Content Analysis

## Project Overview
This project analyzes Netflix content across different countries using Python.

## Dataset
- Dataset: netflix_cleaned.csv
- Total Records: 8,790
- Total Columns: 10

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
1. Handled missing country values.
2. Split multiple countries.
3. Used explode() to expand country records.
4. Calculated country-wise content counts.
5. Identified the Top 10 countries.
6. Created a horizontal bar chart.

## Key Findings
- Identified the top 10 countries based on Netflix content count.
- Compared country-wise content distribution.
- Identified the country with the highest content count.
